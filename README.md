# 서진 · 철민 캐릭터 레퍼런스

기존 공개 캐릭터 시트에서 텍스트와 레이아웃을 제외한 분리본입니다.

- 목 아래부터 발끝까지: 정면·사선·후면
- 머리 포함 전신: 정면·사선·후면
- 얼굴 중심 상반신: 정면·사선·측면

개별 이미지 18개, 3방향 시트 6개. 개별 이미지는 원본 크롭 해상도이며 합본은 레이아웃 크기에 맞춰 리사이즈됩니다.
